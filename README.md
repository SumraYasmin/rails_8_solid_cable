# Task Management with Real-Time Messaging

A modern Rails 8 application for managing tasks with **real-time messaging** powered by Solid Cable and Turbo Streams. Post messages on tasks and see them appear instantly for all users without page refresh.

## 🎥 Demo Video


## ✨ Features

- **Task Management** - Full CRUD operations for tasks
- **Real-Time Messaging** - Post and view messages instantly via Turbo Streams
- **Live Updates** - Messages broadcast to all viewers using Solid Cable
- **Modern UI** - Clean, responsive design with hover effects
- **Auto-Reset Forms** - Message form clears automatically after posting
- **Multi-User Support** - All users viewing a task see new messages in real-time

## 🚀 Tech Stack

- **Ruby** 3.4.2
- **Rails** 8.0.3
- **PostgreSQL** - Primary database
- **SQLite3** - Cable database for Solid Cable
- **Turbo Rails** - SPA-like interactions
- **Stimulus** - JavaScript framework
- **Solid Cable** - Database-backed Action Cable adapter
